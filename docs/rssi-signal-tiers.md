# RSSI 信号强度分档规范

跨端唯一口径。Android 实现：`ui/common/RssiLevel.kt`；测试：`RssiLevelTest`、`RuleEngineTest`。

## 阈值表

| 档位 | 内部名 | dBm 区间（整数） | 4 格制 | 中文 | English |
| --- | --- | --- | --- | --- | --- |
| 很强 | `STRONG` | `>= -55` | 4 | 信号很强 | Strong signal |
| 良好 | `GOOD` | `-66 … -56` | 3 | 信号良好 | Good signal |
| 一般 | `FAIR` | `-75 … -67` | 2 | 信号一般 | Fair signal |
| 较弱 | `WEAK` | `-85 … -76` | 1 | 信号较弱 | Weak signal |
| 极弱 | `VERY_WEAK` | `<= -86` | 0 | 信号极弱 | Very weak signal |
| 未知 | `UNKNOWN` | `null`、哨兵 `Int.MIN_VALUE`、任意非负值 | 0 | 无信号数据 | No signal data |

判定按顺序执行，保证每个输入唯一命中一档：

```
null / Int.MIN_VALUE → UNKNOWN
rssi >= 0            → UNKNOWN      // 非负值不是真实读数
rssi >= -55          → STRONG (4)
rssi >= -66          → GOOD   (3)
rssi >= -75          → FAIR   (2)
rssi >= -85          → WEAK   (1)
其余                  → VERY_WEAK (0)
```

## 边界规则

- 边界值归上一档：`-55` 为 4 格，`-56` 为 3 格；`-66`/`-67`、`-75`/`-76`、`-85`/`-86` 同理。
- 越界负数（如 `-127`）仍是合法读数，归极弱（0 格）。
- 合法 RSSI 恒为负。`0`（云端占位）与 `127`（协议占位）等**任何非负值都归未知档**，不得显示成满格。
- 「未知」与「极弱」都是 0 格但文案不同，不得混用。
- 非 4 格控件：`bars = ceil(level / 4 × N)`，夹取到 `[0, N]`；档位与文案不随格数变化。

## 取值与展示

- 云端同步的 `lastRssi = 0` 是占位，展示层统一经 `Device.localRssi` 转为 `null`；`RssiLevel.isValid` 再兜底所有来源的非负值。
- 未知哨兵只有 `UNKNOWN_RSSI`（`domain/model/Models.kt`）一处定义。
- 首页设备卡仅在**本机已连接**时显示信号格；详情页显示 dBm + 格数 + 读数时间（连接后每 2 秒刷新）；扫描历史只显示 dBm 文字。
- 详情页轮询只在**页面可见且已连接**时运行：`onStop` / 进后台立即停表，回前台且仍连接再起；停表保留已读到的值与时间。
- 单次读取失败（状态非成功、或成功但返回非负值）不清空上次成功值，界面写「刷新失败，显示上次读数 · 时间」；从未成功过则写「读取失败，暂无读数」。
- `readRemoteRssi()` 在途时忽略重复请求；若系统 8 秒内不回调，复位在途标志并标记 `STALE`，避免读数冻结到重连。
- 扫描行与设备卡共用 `RssiLevel.isValid`：非法值不显示 dBm 数值，也不点亮信号格。

## 规则阈值比较符

告警规则（`RuleType.LOW_RSSI`）判定为 **`rssi <= threshold`，达到阈值即触发（含等号）**；恢复条件为 `rssi > threshold`。
RSSI 是整数 dBm，用户设 `-80`、设备停在 `-80` 很常见，旧实现 Android 用 `<`、iOS 用 `<=` 会导致一端告警一端不告警。
指标阈值规则的比较符仍由用户显式选择（`<` / `<=` / `>` / `>=`），不受本条影响。

## 为什么是 -55 / -66 / -75 / -85

级差 11 / 9 / 10 dB，室内约对应「距离翻倍」；-85 比 BLE 典型灵敏度 -95 dBm 留 10 dB 余量，且与场景默认弱信号阈值一致；-55 对应近场（约 0.3–1 m）封顶。数值维持不变。

## 两端剩余差异与决策

| 项目 | iOS | Android | 决策 |
| --- | --- | --- | --- |
| 颜色 | 按档绿 / 橙 / 红 | 全档统一绿 | 允许不同，颜色不影响档位语义 |
| 未连接设备的信号格 | 不显示 | 不显示 | 一致，维持 |
| 详情页信息 | dBm + 格数 + 读数时间 | 同 | 两端都必须显示三项 |
| 未知的内部表示 | `isSignalUnavailable` | `null` / `UNKNOWN_RSSI` | 语义等价，对外表现必须一致 |

iOS 需修正项：阈值改为 `-55 / -66 / -75 / -85`；`nil` 与非负值判未知；补「极弱」文案；规则改为 `<=`；删除 `RSISignalView.swift` 顶部与代码不符的过期注释。
