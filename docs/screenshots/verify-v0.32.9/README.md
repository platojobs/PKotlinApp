# v0.32.9 模拟器走查记录

日期：2026-11-07

本版本两处改动需要实拍核对：

- 底部导航由固定 `56dp` 改为 `wrap_content + minHeight 80dp`，补齐图标 + 文字并整体居中。
- presence 长文案（首页设备行、房间详情设备行与汇总、设备详情「云端状态」行）在 100% / 200% 字号下的换行与挤压。

## 环境与数据

| 项 | 值 |
| --- | --- |
| 模拟器 | AVD `Pixel_10a`，1080×2424 / 420dpi / API 37 arm64，headless（`-no-window -gpu swiftshader_indirect`） |
| 字号 | 系统 `font_scale` 1.0 与 2.0 |
| 后端 | PJGoIoT v0.26.0 + Postgres，App 经 `10.0.2.2:8080` → 宿主转发访问 |
| 数据 | seed 账号（我家 10 台、父母家 3 台、办公室 2 台，含 3 台 iOS 设备） |
| 超时档构造 | `psql` 直接回拨 `user_devices.last_seen_at` 到 15 分钟窗口之外 |
| unknown 档构造 | iOS 设备从未向云端上报（`last_seen_at` 为空） |
| 跨平台 | iOS 设备 `platform = ios`，本机不可连接 |

「在线档」截图采集后 seed 数据会随时间自然超过 15 分钟窗口，因此首页 100% 的在线档与 unknown 档分属两张图，均标注了采集场景。
